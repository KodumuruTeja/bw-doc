What Is BillWallet™?

The One-Liner

"BillWallet is the E-ZPass of bill payments — one-time setup, then fast-lane access every time after."

BillWallet™ is Paymentus' patented digital identity and payment wallet for bill payments. It sits on top of our Intelligent Payment Platform (IPP) and converts one-time guest payers into stored digital relationships.

72% Faster

Payments under 30 seconds for returning users

One-Click

Express Payment — no verification needed for returns

No Passwords

OTC + Google/Apple sign-in. Nothing to steal.

Config Activation

No new integration — enable via script for existing billers

What BillWallet™ Is NOT

  • NOT a replacement for the Customer Portal (CP) or biller portals
  • NOT a retail wallet like Apple Pay / Google Pay
  • NOT a mobile app to download
  • Does NOT support AutoPay (that's core platform)
  • Single-pay only (no multipay currently)

Consumer Touchpoints

How to Enable BillWallet for a Biller

1

Verify Compatibility

Biller must be on Paymentus (TLA in database) and importable to IPN network. Check: no heavy custom account entry, no multipay requirement.

2

Import to IPN Network

The scheduled import-merchant-job runs at 6am/6pm EST. For immediate import, raise an OPAT ticket.

3

Enable on IPN Dashboard

Search for biller → Edit Mode → Enable payment types for BLWT → Check BLWT in Partner Onboarding → Save.

4

Run Enable BillWallet Script

Sets up ROTP, CP, and AD checkout widgets. Options: deactivate "remember me" conflicts, enable BillWallet IVR.

5

Test Payment

Make a BillWallet payment on ROTP/CP/AD. Verify Fast Signup checkbox appears on confirmation page.

For External Biller Websites (SDK)

  1. Register biller as BillWallet partner (get Client ID + Secret)
  2. Provide approved domains for widget loading
  3. Embed JavaScript SDK on biller website
  4. Call Client Credentials API → Client Token API → Initialize widget
